# v1.0.0（2026-10-26）

首个完整业务版本，覆盖收银、进销存、会员、财务、权限与消息通知。

## 新增

**收银与订单**

- 收银台：扫码/搜索开单、会员价、储值卡、组合支付、现金快捷找零、挂单取单
- 销售订单：订单查询、详情、发起退货、取消/恢复/删除
- 退货退款：退货单管理与作废回滚

**商品与库存**

- 商品管理：商品档案（含图片、品牌、供应商、预警线/紧急线）、价格趋势、商品分类、供应商管理
- 库存查询：在途 / 仓库 / 货架三层数量、四种预警状态、补货方式建议
- 库存预警：预警商品排行、批量设置预警线与紧急线
- 入库管理：手动入库与采购入库两条路径
- 出库管理：销售出库（上架）与调拨出库

**采购**

- 采购订单：草稿 → 提交审核 → 审核通过 → 收货入库 → 部分收货 → 完成
- 采购退货：草稿 → 审核 → 确认退货 → 作废回滚

**会员**

- 会员档案、储值卡充值、充值与消费记录

**财务与经营**

- 支付账户、日结管理、收支流水、经营报表
- 经营驾驶舱（今日数据、近 14 天趋势、热销商品、库存预警、业绩排行）
- 经营分析（收入/支出趋势、收入构成、热销排行）

**权限与租户**

- 用户管理、角色三档范围、菜单管理与按钮权限、登录日志、操作日志
- 租户（客户）管理、品牌门店、套餐管理、系统管理工作台

**消息通知**

- 消息中心：系统公告 / 我的通知 / 事件提醒三个页签，文章版式详情
- 平台公告：类型、定向范围（全部/按套餐/指定租户）、强制确认、仅管理员、已读确认统计
- 租户通知：三种类型、按门店/角色/人员定向、撤回与重新发布、已读统计
- 顶部未读消息滚动条（按类型分色，可关闭）

## 优化

- 商品列表新增「货架」列，直观区分仓库库存与可售库存
- 商品列表移除「供应商」列，精简列表宽度
- 热销商品改为卡片式展示：商品图片 + 售价 + 库存状态 + 销量
- 消息详情统一为文章版式，富文本正文支持图片、视频、表格
- 角色授权保存时自动补齐半选父目录，避免菜单扁平化

## 修复

- 平台公告撤回后无法重新发布
- 租户通知缺少撤回与重新发布能力
- 富文本编辑器图片、视频上传无法使用
- 菜单权限只勾子页面导致侧边栏菜单扁平化

## 不兼容变更

无。

## 已知限制

以下为当前版本的已知情况，使用时请注意：

- **日结管理**：实时计算展示，不落库保存，需要留档请自行导出
- **收支流水「记一笔」**：未对接后端，记录不会保存
- **经营报表支出**：目前只统计销售退款，不含采购、人工等成本
- **POS 挂单**：保存在浏览器本地，刷新或换设备后丢失
