# 更新日志

记录每个版本的新增、优化与修复。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，按中文四分类整理。

## 分类含义

| 分类 | 含义 |
| --- | --- |
| 新增 | 新上线一个功能或页面 |
| 优化 | 已有功能的体验或性能改进 |
| 修复 | 修正了一个错误 |
| 不兼容变更 | 升级后需要人为处理的变化（数据结构、操作流程改变） |

## 版本列表

| 版本 | 日期 | 主题 |
| --- | --- | --- |
| [v1.0.0](/changelog/v1.0.0) | 2026-10-26 | 首个完整业务版本：收银、进销存、会员、财务、权限、消息通知 |

## 升级前请注意

- 版本中的**不兼容变更**会列出需要你处理的事项，升级前务必先看
- 数据库变更脚本位于 `backend/src/main/resources/db/`，按文件名顺序执行，脚本均为幂等设计（可重复执行）
- 每次发版建议在[平台公告](/guide/notify)中同步发布一条「功能更新」公告
