# 常见问题

按问题场景分类，找不到答案请联系系统管理员。

## 库存相关

### 收银台提示「当前门店货架无库存」，但库存查询里明明有货

库存查询里的数量是**三层合计**（在途 + 仓库 + 货架），而收银台只看**货架**这一层。

处理：仓库有货 → 到「仓库管理 → 出库管理 → 销售出库」新建上架单并**确认上架**；仓库也空了 → 先[采购收货](/guide/purchase)。

### 撤销上架失败，提示货架库存不足

这批货上架后已经在收银台卖掉了一部分，货架上的数量少于要撤销的数量。

处理：先补齐货架库存（再上架或调拨），或者只撤销能撤销的部分。

### 收货入库后，收银台还是卖不了

收货入库把货放进了**仓库**层，还要做上架才能变成货架库存。这是两步，不是一步。

### 预警线和紧急线该设多少

建议 预警线 = 日均销量 × 补货周期天数（如日均卖 5 件、3 天补一次，就设 15）；紧急线设为预警线的一半左右。批量设置在「库存预警」页操作。

## 收银相关

### 挂单后刷新页面就没了

挂单数据存在浏览器本地，不上传服务器。刷新、关闭浏览器、换设备都会丢失。长时间不用请先把单子结算或记下来。

### 顾客用储值卡付款失败

两个常见原因：① 收银时没有先关联会员（储值卡必须先关联）；② 会员余额不足。

### 现金收款算错找零

收银台有 `100` / `200` / `500` 快捷键和 `正好` 按钮，用按钮少手输，系统自动算找零。

### 商品售价错了怎么处理

售价在「商品管理 → 商品列表」编辑里改，改完可在「价格趋势」查看历史走势。已经成交的订单不受影响。

## 订单与退货

### 退货单页没有「新增」按钮

退货必须由销售订单页发起：找到原订单 → 发起退货。退货单页只用于查看与作废。

### 作废退货单后库存变成负数

作废会把之前退回的库存再扣回去。作废前先确认货架上还有足够的量。

### 订单删错了能恢复吗

不能。删除订单不可恢复，只是录错请用「取消订单」（可再恢复）。

## 权限与菜单

### 用户看不到某个菜单

按这个顺序排查：

1. 该用户的**角色**是否正确
2. 角色 → 菜单权限 → 是否勾了该页面
3. **父目录是否也勾上了**（只勾子页面会导致菜单扁平化甚至不显示）
4. 菜单本身的「启用」开关是否打开

用超管的**模拟登录**进用户账号看一眼最快。

### 菜单权限勾了，保存后又不显示

检查菜单的路由地址是否与前端路径一致（如 `/product/list`）。路径写错会导致授权错乱。

### 按钮点了没反应 / 按钮不显示

按钮级权限未授予。在「菜单管理」里找到对应菜单下的按钮权限，通过角色授权。

## 消息通知

### 顶部没有消息滚动条

滚动条只显示**未读**消息，且需要该消息定向到你（或你所在的门店/角色）。全部已读后滚动条自然消失，点过 × 关闭后本次也不再展示。

### 员工说没收到通知

检查：接收范围是否包含他所在的门店/角色/本人；通知是否被撤回；他是否属于目标租户。

### 公告撤回后想再发一遍

在列表里该条状态为「已撤回」，操作菜单里点**重新发布**。注意重新发布不会提醒已经读过的人，重要更正建议新发一条。

## 财务与报表

### 日结数据隔天看不到了

日结是实时计算展示，不保存历史快照。需要留档请当天导出或另行登记。

### 手工记账的记录不见了

「记一笔」功能尚未对接后端，数据不保存。正式记账请使用真实业务单据。

### 报表里的支出只有退款

当前支出统计口径只有销售退款，不含采购、人工等成本。

## 数据维护

### 删除商品/用户/会员能恢复吗

都不能恢复。

- 商品：已产生单据的商品建议改为「停售」而不是删除
- 会员：删除会连带删除其充值记录
- 用户：删除后不可恢复，停用即可保留数据

### 换门店后数据看不到了

库存、订单、收银数据按门店隔离，切换门店看到的是另一套数据。收银前先确认门店选对了。
