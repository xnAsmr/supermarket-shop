## 怎么用这本手册

本手册按**实际业务角色**组织，不需要通读：

| 你的角色 | 建议先看 |
| --- | --- |
| 收银员 / 店员 | [收银台](/guide/pos) → [销售订单与退货](/guide/order) → [会员管理](/guide/member) |
| 店长 | [库存管理](/guide/inventory) → [采购管理](/guide/purchase) → [经营分析](/guide/analysis) |
| 租户管理员 | [商品管理](/guide/product) → [用户与角色](/guide/system) → [消息通知](/guide/notify) |
| 平台超管 | [客户与门店](/guide/tenant) → [消息通知](/guide/notify) |

::: tip 手册维护约定
每篇文档对应系统中的真实页面。功能调整时，同步更新对应文档并在[更新日志](/changelog/)中记录一条变更。
:::
