# 商品管理

> 「商品管理」下的商品列表、商品分类、供应商管理三个页面。商品是所有进销存数据的起点。

## 商品列表

展示字段：序号 / 图片 / 商品信息（名称 + 条码 + 规格）/ 分类 / 单位 / 进价 / 售价 / 会员价 / **库存** / **货架** / 销量 / 毛利率 / 状态 / 更新时间 / 操作。

顶部搜索支持：商品名称、条码、分类、状态。

### 库存 与 货架 两列的区别

这是两个不同层级的库存，别看混了：

| 列 | 含义 |
| --- | --- |
| **库存** | 仓库 + 货架的**合计**数量，低于预警线时显示红色标签 |
| **货架** | 已上架到货架的数量，**这才是收银台能卖的数量** |

一批货收货后先进仓库（库存增加、货架不变），做完「上架」后才会变成货架库存。详见[库存管理](/guide/inventory)。

### 状态

| 状态 | 含义 |
| --- | --- |
| 在售 | 可销售，收银台能搜到 |
| 停售 | 下架状态，收银台不再展示 |

## 新增商品

点 **新增商品**，弹窗内分几个部分填写：

**基础信息**

| 字段 | 说明 |
| --- | --- |
| 商品名称 | 必填，收银台搜索与显示用 |
| 商品条码 | 必填，扫码收银的关键 |
| 商品分类 | 选择已建的分类 |
| 品牌 | 选填 |
| 供应商 | 选填，用于采购时带出 |
| 单位 / 规格 | 如「瓶」「500ml」 |

**价格**

| 字段 | 说明 |
| --- | --- |
| 进价 | 采购成本，影响毛利与库存金额 |
| 售价 | 零售价，会员未关联时按此价 |
| 会员价 | 会员关联后的价格 |

**库存与预警**

| 字段 | 说明 |
| --- | --- |
| 预警库存 | 货架库存低于此值进入预警，建议 ≥ 10 |
| 紧急库存 | 货架库存低于此值进入紧急状态，应小于预警线 |
| 初始仓库 | 新建商品时把期初库存记到哪个仓库 |
| 初始库存 | 期初数量，直接进仓库层 |

**销售状态、商品图片、备注**在最下方。

::: tip 初始库存只在新增时可用
初始库存会把数量直接写入「仓库」层，商品建完后要卖，还得去[出库管理做上架](/guide/inventory)。
:::

## 编辑与删除

- **编辑**（铅笔图标）：修改名称、价格、图片等。价格改动会被记录下来
- **价格趋势**（查看图标）：查看该商品的进价/售价历史走势，用于复盘调价
- **删除**（垃圾桶图标）：删除后**不可恢复**。已产生销售、采购单据的商品不建议删除，用「停售」更安全

## 商品分类

路径：商品管理 → 商品分类。树形结构，支持多级。

- 分类直接决定收银台左侧的分类筛选，建分类时想好收银员的查找习惯
- 列表显示每个分类下的商品数；有商品的分类不能随便删
- 排序值越小越靠前

## 供应商管理

路径：商品管理 → 供应商管理。

维护供应商名称、联系人、联系电话、地址、备注与状态，列表显示每个供应商供应的商品数。供应商在建商品时选填、在[采购下单](/guide/purchase)时作为必选对象。
