# 消息通知

> 系统里有两种消息：**平台公告**（平台超管发布，全网通知）和**租户通知**（租户内部发），加上业务自动产生的**事件提醒**，统一在消息中心查看。

## 消息中心

路径：消息通知 → 消息中心。所有角色都能用。

三个页签：

| 页签 | 内容 |
| --- | --- |
| 系统公告 | 平台发布的公告 |
| 我的通知 | 本租户发给我的通知 |
| 事件提醒 | 业务事件自动产生的提醒（如采购审批） |

每个页签右上角有 **全部标记已读**，可一键清空该类型的未读。

### 详情弹窗

点开一条消息，以文章版式展示：标题上方是类型标签，标题下方是来源与时间，正文支持富文本（图片、视频、表格）。

底部三个操作：

| 按钮 | 作用 |
| --- | --- |
| 标记已读 | 标记为已读，未读数 -1 |
| 我已知晓 | 公告要求强制确认时出现，确认后计入"已确认"统计 |
| 前往处理 | 业务类提醒（如采购审批）直接跳到对应页面处理 |

### 顶部滚动条

多标签栏下方会滚动播放你**未读**的消息标题，按类型分色：

| 类型 | 颜色 |
| --- | --- |
| 系统公告 | 红色 |
| 我的通知 | 主题色 |
| 事件提醒 | 橙色 |

点标题直接进消息中心看详情；右侧 × 可关闭，关闭后本次登录不再展示。

## 平台公告

路径：消息通知 → 平台公告。**仅平台超级管理员可用。**

展示字段：标题 / 发布人 / 类型 / 定向范围 / 生效时间 / 状态 / 已读 / 确认 / 创建时间 / 操作。

### 发布一条公告

1. 点 **新增公告**
2. 填写标题，正文用富文本编辑器（支持图片、视频、表格、列表）
3. 选择类型与定向范围（见下）
4. 设定生效 / 失效时间（生效时间留空 = 立即生效；失效时间留空 = 长期有效）
5. 按需开启**强制确认**、**仅系统管理员**
6. 保存：开启「发布方式」开关 = 保存后立即发布；关闭 = 存为草稿

| 类型 | 用途 |
| --- | --- |
| 功能更新 | 上新功能时 |
| 系统维护 | 停机维护、升级通知 |
| 规则变更 | 业务规则、政策调整 |

| 定向范围 | 说明 |
| --- | --- |
| 全部租户 | 平台内所有客户 |
| 按套餐 | 只发给订阅了指定套餐的客户 |
| 指定租户 | 勾选具体客户 |

### 公告状态与操作

| 状态 | 含义 | 可用操作 |
| --- | --- | --- |
| 草稿 | 未发布 | 编辑、发布、删除 |
| 已发布 | 生效中 | 撤回、已读统计、编辑 |
| 已撤回 | 已下架 | **重新发布**、编辑、删除 |

撤回后接收人那边立刻看不到，也不会计入未读；**重新发布**不会重复打扰已经读过的人。

### 强制确认与仅管理员

- **强制确认**：开启后接收人必须点「我已知晓」，用于重要规则、停机通知等必须留痕的场景
- **仅系统管理员**：开启后只发给目标范围内的租户管理员，不打扰普通员工

### 已读统计

行操作 → **已读统计**，看三个数（覆盖用户 / 已读 / 已确认或已读率）以及按租户的明细，用于追踪传达效果。

## 租户通知

路径：消息通知 → 租户通知。**租户管理员可用**，店长只能处理本门店的通知。

展示字段：类型 / 标题 / 接收范围 / 发送人 / 发送时间 / 状态 / 应读已读 / 已读率 / 创建时间 / 操作。

### 发送一条通知

1. 点 **发送通知**
2. 选类型、填标题与正文（富文本）
3. 选择接收范围（见下）
4. 保存发送

| 类型 | 用途 |
| --- | --- |
| 门店通知 | 日常店务、运营提醒（默认） |
| 制度规范 | 规章制度、流程标准 |
| 活动安排 | 促销、盘点、培训等计划事项 |

| 接收范围 | 说明 |
| --- | --- |
| 全租户 | 本租户所有人 |
| 指定门店 | 只有这几家门店的人 |
| 指定角色 | 只有持有该角色的人 |
| 指定人员 | 勾选具体的人 |

### 状态与操作

| 状态 | 含义 | 可用操作 |
| --- | --- | --- |
| 已发送 | 生效中 | 编辑、撤回、已读统计、删除 |
| 已撤回 | 已下架 | **重新发布**、编辑、删除 |

撤回后员工端立刻不可见、不计未读；重新发布会刷新发送时间，但已经读过的人不会被重复提醒。

### 已读统计

行操作 → **已读统计**，查看谁还没看、以及各门店的已读率，方便督促。

## 使用建议

- **重要通知开启强制确认**，否则不知道员工到底看没看
- **按门店定向**，别把 A 店的事情发给全公司
- **撤回要谨慎**：撤回后重新发布不会提醒已读的人，重要更正请直接再发一条新通知
- 更新系统时，用**功能更新**类型的公告同步告知用户（配合[更新日志](/changelog/)）
