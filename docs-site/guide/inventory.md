# 库存管理

> 库存分**仓库**和**货架**两层。货进来到仓库，上架到货架后才能在收银台卖出去。理解这一条，整个库存流程就通了。

## 三层数量

```text
在途  →  仓库  →  货架
        （已收货但未上架）  （收银台可售）
```

| 层级 | 含义 | 在哪儿产生 |
| --- | --- | --- |
| 在途 | 已下采购订单、还没收货 | [采购订单](/guide/purchase) 生成 |
| 仓库 | 已收货入库 | 采购「收货入库」、手动入库 |
| 货架 | 已上架，可直接销售 | 出库管理「销售出库（上架）」 |

**收银台扣减的是货架库存。** 仓库里有货但没上架，收银台会提示「当前门店货架无库存」。

## 库存查询

路径：仓库管理 → 库存查询

展示字段：商品信息 / 仓库 / 在途 / 仓库 / 货架 / 合计 / 预警线与紧急线 / 状态 / 进价。

顶部三张统计卡：

| 卡片 | 含义 |
| --- | --- |
| 预警商品 | 货架库存低于预警线 |
| 紧急商品 | 货架库存已触及紧急线 |
| 缺货商品 | 货架库存为 0，收银台卖不了 |

### 四种状态与补货方式

| 状态 | 触发条件 | 系统建议的补货方式 |
| --- | --- | --- |
| 正常 | 货架 ≥ 预警线 | 不用管 |
| 预警 | 货架 < 预警线 | **可上架**：仓库有货，直接上架 |
| 紧急 | 货架 < 紧急线 | **在途补货中**：仓库空了，但有采购在途，等收货 |
| 缺货 | 货架 = 0 | **需采购**：仓库和在途都空了，得先下单 |

跟着补货方式走就行：可上架 → 去出库管理上架；需采购 → 去采购管理下单。

## 库存预警

路径：仓库管理 → 库存预警

只显示货架不足的商品，按严重程度排序：**缺货 → 紧急 → 预警 → 正常**。

### 批量设置预警线 / 紧急线

1. 点 **批量设置预警线/紧急线**
2. 在弹窗里搜索商品（名称或条码），勾选需要调整的商品
3. 填写预警线、紧急线 —— 紧急线不能大于预警线
4. 点 **应用到选中（N）** 或 **应用到全部（N）**

未勾选任何商品时，「应用到全部」会作用于当前搜索结果。

::: tip 阈值怎么定
预警线按「日均销量 × 补货天数」来定更合理。卖得快的商品预警线设高一点，避免等到缺货才补。
:::

## 入库管理

路径：仓库管理 → 入库管理

展示字段：单据号 / 类型 / 来源仓库 / 来源采购订单 / 目标仓库 / 总数量 / 状态 / 制单人 / 创建时间 / 完成时间 / 操作。

### 入库单状态

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 草稿 | 手动新建的入库单 | 点「完成」 |
| 待入库 | 来自采购收货 | 点「确认入库」 |
| 已完成 | 库存已增加 | — |
| 已取消 | 作废 | — |

手动新建的入库单走「新建入库单 → 完成」两步：点「完成」时系统自动审核并入库。采购来的入库单点「确认入库」才真正加库存。

入库后库存进的是**仓库**层，要卖还得上架。

## 出库管理

路径：仓库管理 → 出库管理。用分段控件切换两种业务。

### 销售出库（上架）— 常用

展示字段：上架单号 / 门店 / 上架数量 / 状态 / 制单人 / 上架人 / 上架时间 / 创建时间 / 操作。

流程：

```text
新建上架单（草稿） → 确认上架 → 已上架 →（可撤销上架）
```

1. 点 **新建销售出库**，选择商品与数量
2. 填数量时系统会显示**当前仓库库存 / 当前货架库存**供参考，仓库不足会标红提示
3. 点 **确认上架** —— 弹窗会提示「仓库库存将减少 N，货架库存将增加 N，商品即可在收银台销售」
4. 上架完成，收银台立刻能卖

| 状态 | 含义 |
| --- | --- |
| 草稿 | 未生效，可编辑或删除 |
| 已上架 | 已生效，可撤销 |
| 已撤销 | 已回退，只能看详情 |

::: warning 撤销上架的坑
撤销会把货架库存扣回仓库。如果这批货已经在收银台卖掉了一部分，货架数量不够就会撤销失败，提示无法撤销。这时候得先补库存再撤销。
:::

### 调拨出库

门店之间调货用。流程：新建调拨单 → 完成 → 已完成。目标仓库与来源仓库必填。

## 一条完整的补货链路

```text
库存查询发现缺货
   ↓ 仓库也没货
采购管理：新建采购订单 → 提交审核 → 审核通过 → 收货入库（进仓库层）
   ↓
出库管理：新建销售出库（上架单） → 确认上架（仓库 → 货架）
   ↓
收银台可以卖了
```

仓库有货时，直接从**出库管理上架**开始即可，不用走采购。

## 常见疑问

**收银台提示无库存，但库存查询显示有货？**
有的是仓库库存（还没上架），收银台只看货架。去出库管理做上架。

**上架数量不小心填多了？**
数量超过仓库库存时系统会提示「超出仓库库存」，及时改回即可。
