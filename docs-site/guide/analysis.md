# 经营分析

> 「工作台」下的两个看板：**经营驾驶舱**看今天，**经营分析**看一段时期。

## 经营驾驶舱

路径：工作台 → 经营驾驶舱。面向店长和管理者，一屏看完当天状况。

### 顶部四张卡

| 卡片 | 说明 |
| --- | --- |
| 今日销售额 | 当天实收金额 |
| 今日订单数 | 当天成交笔数 |
| 今日毛利 | 当天销售毛利 |
| 客单价 | 今日销售额 ÷ 今日订单数 |

### 主要区块

| 区块 | 看什么 |
| --- | --- |
| 近 14 天销售趋势 | 每天的销售额走势，判断淡旺 |
| 业绩排行 | 总部看**门店营业额**，门店内看**收银员业绩**（按订单数） |
| 近 7 天热销商品 | 商品缩略图 + 售价 + 库存状态 + 销量，点「查看全部」进商品列表 |
| 库存预警 | 货架不足的商品与剩余数量，提示需要补货的 SKU 数 |
| 最近订单 | 最新几笔订单，可跳订单管理查看详情 |

::: tip 热销商品的库存状态
热销排行里显示的库存状态（库存充足 / 库存紧张 / 暂时缺货）是按**仓库 + 货架合计**判定的，用于快速发现"卖得好但快没货了"的商品。
:::

## 经营分析

路径：工作台 → 经营分析。可切换时间范围。

| 区块 | 内容 |
| --- | --- |
| 收入趋势 | 折线图，按天看收入变化 |
| 支出趋势 | 柱状图，主要是退款产生的支出 |
| 收入构成 | 按支付方式拆分（现金 / 微信 / 支付宝 / 银行卡 / 储值卡）与占比 |
| 热销商品排行 | 商品 + 售价 + 库存状态 + 销量 |

## 怎么用这些数据

- **热销但库存紧张** → 立刻补货，这是最容易损失营业额的情况
- **收入构成里储值卡占比高** → 会员储值活跃，可继续推充值活动
- **连续多日销售额下滑** → 结合库存预警看看是不是缺货导致的
- **客单价偏低** → 考虑做组合促销
