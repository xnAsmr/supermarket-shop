# 销售订单与退货

> 收银产生的每一笔单据，都在「订单管理」里查得到、退得掉。

## 销售订单

路径：**订单管理 → 销售订单**

列表展示字段：序号 / 订单号 / 商品数 / 原价 / 优惠 / 实收 / 支付方式 / 状态 / 门店 / 收银员 / 下单时间 / 操作。

### 查询

搜索栏支持：关键词（订单号 / 会员 / 收银员 / 商品）、订单状态、门店、下单日期范围。

### 订单状态

| 状态 | 含义 |
| --- | --- |
| 已完成 | 正常收款完成 |
| 部分退款 | 已退了一部分商品 |
| 已全额退款 | 整单退完 |
| 已取消 | 订单被取消，可再恢复 |

### 可以做的事

| 操作 | 可用时机 | 说明 |
| --- | --- | --- |
| **订单详情** | 随时 | 抽屉展示商品明细（商品 / 单位 / 单价 / 数量 / 已退 / 金额）与支付记录 |
| **发起退货** | 已完成、部分退款 | 见下方退货流程 |
| **取消订单** | 非已取消、非已全额退款 | 原因最多 100 字 |
| **恢复订单** | 仅已取消 | 撤销取消 |
| **删除订单** | 仅已取消 | 彻底删除，**不可恢复** |

::: danger 删除订单不可恢复
删除前请确认这笔单不再需要留痕。只是录错了，用「取消订单」更安全。
:::

## 发起退货

退货**只能从销售订单页发起**，退货单页不提供新增入口。

1. 找到订单 → 行操作 → **发起退货**
2. 在弹窗中逐商品填写本次退货数量 —— 可退数量 = 购买数量 − 已退数量，为 0 的商品不可再退
3. 选择退款方式：**现金退款** 或 **原路退回**
4. 填写退货原因（必填，最多 200 字）
5. 点 **确认退货**

退货成功后，原订单会变为「部分退款」或「已全额退款」，库存同步回补。

::: tip 储值卡订单怎么退
含储值卡支付的订单，储值卡部分会退回到会员余额里，不会退现金。
:::

## 退货退款

路径：**订单管理 → 退货退款**

集中展示所有退货单：退货单号 / 原订单号 / 门店 / 退款金额 / 退款方式 / 状态 / 退货原因 / 操作人 / 退货时间 / 操作。

| 状态 | 含义 |
| --- | --- |
| 待处理 | 已生成，待处理 |
| 已完成 | 退款完成 |
| 已驳回 | 未通过 |
| 已作废 | 已回滚 |

行操作：

- **退货单详情**：查看退货单信息与退货明细
- **作废退货单**：仅「已完成」状态可用。作废后系统会扣回已回补的库存、恢复支付账户金额，并恢复原订单的退款状态

::: warning 作废影响库存
作废退货单会把之前退回的库存再扣回去。如果这批货已经又卖掉了，请先补齐库存再作废，否则会出负数库存。
:::
