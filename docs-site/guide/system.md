# 用户与角色

> 「系统管理」下的用户管理、角色管理、菜单管理，以及两个日志页面。这决定了谁能看到什么、能做什么。

## 用户管理

路径：系统管理 → 用户管理

展示字段：用户名（头像 / 昵称 / 工号）/ 性别 / 账号 / 手机号 / 租户 / 角色 / 状态 / 创建日期 / 操作。

### 新增用户

1. 点 **新增用户**
2. 填写账号、用户名、手机号、初始密码
3. 分配角色（决定该用户能看到哪些菜单、能点哪些按钮）
4. 保存

| 字段 | 说明 |
| --- | --- |
| 状态 | 启用的账号才能登录 |
| 用户类型 | 普通用户 / 系统管理员 / 超级管理员（**仅超管可见可改**） |

### 其他操作

| 操作 | 说明 |
| --- | --- |
| 编辑 | 改资料与角色；**密码不在编辑里改** |
| 重置密码 | 单独的操作，需要对应权限 |
| 删除 | 删除后不可恢复 |
| 模拟登录 | **仅超管可用**，以该用户身份进入系统排查问题，可退出还原 |

::: tip 用户反馈"看不到某个功能"时
用**模拟登录**进他的账号看一眼，比反复问"你看到的是什么样"快得多。
:::

## 角色管理

路径：系统管理 → 角色管理

展示字段：角色 ID / 角色名称 / 角色编码 / **范围** / 角色描述 / 角色状态 / 创建日期 / 操作。

### 角色范围三档

| 范围 | 含义 |
| --- | --- |
| **租户私有** | 仅本租户可用，租户自己维护（默认） |
| **平台共享** | 所有租户都能用，**只有超管能维护** |
| **平台内置** | 只有超管能用（如平台管理员角色） |

非超管看到「平台共享」「平台内置」的行时，操作区显示「仅超管可维护」，不能改也不能删。

### 授权：菜单权限

1. 在角色行 → 三点菜单 → **菜单权限**
2. 在菜单树里勾选该角色能访问的页面
3. 点 **保存**

::: danger 保存前先检查父目录
菜单树里的父目录（如「系统管理」）必须处于**选中**状态。只勾了子页面而父目录是半选状态，保存后父目录会被丢弃，用户那边看到的就是一堆散落的一级菜单。
:::

树下方有「全部展开 / 全部收起」「全部选择 / 取消全选」方便批量操作。

### 按钮级权限

按钮权限（如"删除""审核"）以权限标识挂在菜单下，在「菜单管理」中定义，通过角色的菜单权限一并授予。用户没有某按钮权限时，按钮不显示或不可用。

## 菜单管理

路径：系统管理 → 菜单管理

展示字段：菜单名称 / 菜单类型 / 路由 / 权限标识 / 编辑时间 / 状态 / 操作。

### 五种菜单类型

| 类型 | 说明 |
| --- | --- |
| 目录 | 有子菜单的父节点 |
| 菜单 | 具体页面 |
| 按钮 | 挂在菜单下的权限点 |
| 内嵌 | iframe 嵌入的页面 |
| 外链 | 跳到外部链接 |

### 常用操作

| 操作 | 说明 |
| --- | --- |
| 添加菜单 | 新建目录或页面 |
| 新增权限 | 在某菜单下新增按钮权限（弹窗里填权限名称与权限标识） |
| 编辑 | 修改菜单信息；**类型在编辑时锁定不可改** |
| 删除 | 删除后不可恢复 |

::: warning 路由地址必须写对
菜单的「路由地址」必须与前端页面路径一致（如 `/product/list`），否则授权树会错乱，出现"授权了但菜单不显示"的怪问题。新增页面时务必按开发给的路由填写。
:::

### 八个开关

菜单表单下方有：启用 / 页面缓存 / 隐藏菜单 / 内嵌 / 显示徽章 / 固定标签 / 标签隐藏 / 全屏页面。日常最常用的是**启用**（关掉就不显示）和**页面缓存**。

## 登录日志

路径：系统管理 → 登录日志。**只读**，用于排查"账号是不是被盗用""为什么登不上"。

展示字段：用户名 / 租户 / 登录类型 / 状态 / IP / 浏览器 / 操作系统 / 消息 / 登录时间。

- 登录类型：后台登录 / POS 登录
- 状态：成功 / 失败
- 筛选：用户名、登录类型、状态、日期区间

## 操作日志

路径：系统管理 → 操作日志。**只读**，记录业务操作留痕。

展示字段：模块 / 操作 / 用户 / 租户 / 状态 / IP / 耗时 / 操作时间 / 操作。

点 **详情** 可看到：模块、操作、描述、用户、租户、状态、方法、URL、IP、耗时、时间，以及**报错信息 / 请求参数（敏感字段已脱敏）/ 返回结果**。

排查"用户说操作失败了"时，先来这里按时间和用户筛选，看报错信息。

## 个人中心

路径：系统管理 → 个人中心。修改自己的资料与密码，不需要额外权限。
