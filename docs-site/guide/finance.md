# 财务与日结

> 「财务管理」下的支付账户、日结管理、收支流水、经营报表。

## 支付账户

路径：财务管理 → 支付账户

管理收银时能选的支付方式：账户名称 / 支付编码 / 类型 / 状态 / 余额 / 备注 / 创建时间。

**类型由支付编码决定**：

| 编码 | 类型 |
| --- | --- |
| cash | 现金 |
| wechat | 微信 |
| alipay | 支付宝 |
| card | 银行卡 |
| stored | 储值卡 |

其他编码显示为「自定义」。编码只能用小写字母、数字、下划线，且必须以字母开头。

::: tip 余额不可手工修改
余额由收银结算和会员充值自动维护，不能编辑。想调整就做一笔真实的退款或充值。
:::

停用的账户不会出现在收银台的支付方式里。想在收银台加新的支付方式，在这里新增并启用即可。

## 日结管理

路径：财务管理 → 日结管理

展示字段：日期 / 销售额 / 退款额 / 收入 / 支出 / 结余 / 订单数 / 状态 / 操作人 / 生成时间。

- **结余 = 收入 − 支出**，为正显示绿色，为负显示红色
- 点 **生成今日日结** 汇总当天数据
- 查询时日期按 `yyyy-MM-dd` 精确填写

::: warning 日结单不会保存
当前日结是**实时计算**的展示结果，不落库保存。刷新或隔天再看，看到的是当天实时的计算结果，而不是历史快照。需要留档请自行导出或登记。
:::

## 收支流水

路径：财务管理 → 收支流水

逐笔展示：流水号 / 类型 / 分类 / 金额 / 方式 / 关联单号 / 操作人 / 发生时间 / 备注。

来源：收款 → 收入 / 销售收款；退款 → 支出 / 销售退款。

支持按流水类型、收支分类、流水号、关联单号、发生日期筛选。

::: danger 「记一笔」目前只存在本地演示中
手工记账功能尚未对接后端接口，记录的数据不会真正保存。正式记账请使用收银台收款、采购付款等真实业务单据。
:::

## 经营报表

路径：财务管理 → 经营报表

顶部切换 **近 7 天 / 近 30 天 / 近 90 天**（默认近 30 天）。

四张统计卡：

| 卡片 | 算法 |
| --- | --- |
| 总收入 | 区间内收款合计 |
| 总支出 | 区间内退款金额 |
| 净利 | 收入 − 支出，同时显示净利率 |
| 订单数 | 区间内订单笔数，同时显示客单价 |

图表：收入趋势（折线）、支出趋势（柱状）、收入构成（按支付方式）、支出构成。

::: tip 支出目前只统计退款
报表里的「支出」目前只有销售退款这一类，不含采购、人工等成本。看净利润时请知悉这个口径。
:::

## 典型用法

**每天收工对账**

1. 财务管理 → 日结管理，看当天销售额、退款额、结余
2. 收支流水，核对每一笔收款方式是否和收银台回收的现金对得上
3. 有差异 → 到[销售订单](/guide/order)里逐单核对

**每月看经营**

1. 经营报表切到「近 30 天」
2. 看净利与客单价
3. 对照[经营分析](/guide/analysis)的热销商品，决定下个月备货重点
