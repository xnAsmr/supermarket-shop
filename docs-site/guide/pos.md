# 收银台

> 「收银管理 → 收银台」，门店现场开单收款的主页面。

## 开单前的准备

收银台的库存取的是**货架库存**，不是仓库库存。商品只有完成「上架」（见[库存管理](/guide/inventory)）后，才能在收银台被卖出去——这一点是理解整个库存体系的关键。

进入页面后先做两件事：

1. 顶部**销售门店**下拉：切换到当前收银的门店
2. 确认商品已在列（列表视图 / 卡片视图可切换）

## 标准收银流程

```text
扫码或搜索商品 → 加入购物车 → （可选）关联会员
              → 选择支付方式 → 结算 → 收款成功 → 完成
```

### 1. 找商品

- **扫码**：光标定位到搜索框，扫商品条码/名称，回车加入购物车
- **手选**：按左侧一级/二级分类筛选，或直接搜索名称
- 售罄的商品卡片会**置灰且不可点击**，提示「当前门店货架无库存」

### 2. 调整购物车

购物车里每行可以：

- `－` / `＋` 增减数量
- `删除` 去掉该行
- `清空` 清空整单

改数量时若超过货架库存，会提示「商品 X 货架库存不足（剩余 N 件）」。允许超量录入但会提示**超卖风险**，请谨慎处理。

### 3. 关联会员（可选）

输入会员**手机号**点「查询」即可关联。关联后：

- 商品自动按**会员价**计价，折扣由系统计算，**不能手工改**
- 已停用的会员无法关联，会提示原因
- 点「解除」取消关联，价格回到零售价

::: tip 储值卡支付必须先关联会员
用会员储值卡收款时，必须先关联会员；余额不足时会提示更换支付方式。
:::

### 4. 收款

选择支付方式后点「结算 ¥ x.xx」：

| 支付方式 | 说明 |
| --- | --- |
| 现金 | 填写实收金额，系统自动算找零 |
| 微信 / 支付宝 / 银行卡 | 直接收款 |
| 储值卡 | 需先关联会员，扣会员余额 |
| 组合支付 | 点「+ 添加支付方式」，一行填一个账户与金额，合计必须与应收一致 |

现金收款支持 `100` / `200` / `500` 快捷按键和 `正好` 按钮，提高收银速度。

### 5. 完成

弹出「收款成功」，显示订单号、件数、实收与找零，点「完成」即清空购物车，可接待下一位顾客。该笔订单随后可在「订单管理 → 销售订单」中查到。

## 挂单与取单

顾客临时离开、商品要再加时，用**挂单**：

1. 点「挂单」，把当前购物车暂存
2. 继续接待下一位顾客
3. 点「取单」→ 在「挂单列表」中找到那单 → 取单恢复

挂单列表里可以对单条记录取单或删除。

::: warning 挂单是本机临时记录
挂单数据保存在当前浏览器，不会上传到服务器。**不要关闭浏览器或刷新页面**，换设备也取不到。
:::

## 最近交易

收银台右侧展示最近的若干笔交易（订单号 / 金额 / 收银员 / 时间），方便当场核对。

## 常见提示与处理

| 提示 | 含义 | 怎么处理 |
| --- | --- | --- |
| 请选择销售门店 | 未选门店 | 顶部先选门店 |
| 商品 X 当前门店货架无库存 | 该门店没上架货 | 先做上架，或换门店 |
| 实收金额不足，请调整实收金额 | 现金不够 | 补收或改支付方式 |
| 请输入正确的会员手机号 | 手机号格式不对 | 用 11 位手机号 |
| 未找到该手机号对应的会员 | 该号未建档 | 先到会员管理建档 |
| 会员卡余额不足 | 储值卡钱不够 | 换支付方式或减少商品 |
| 组合支付收款合计与应收金额不一致 | 拆分金额对不上 | 调整各行金额使合计等于应收 |

## 收银员的权限边界

收银台只负责**卖货收款**。以下动作不在收银台做，各自有独立页面与权限：

- 退货退款 → [订单管理](/guide/order)
- 会员充值、建档 → [会员管理](/guide/member)
- 改价、建档商品 → [商品管理](/guide/product)
- 看当日账目 → [财务与日结](/guide/finance)
