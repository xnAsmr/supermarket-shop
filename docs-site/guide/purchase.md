# 采购管理

> 从「我要进货」到「货进仓库」的完整闭环。路径：采购管理。

## 采购订单

路径：采购管理 → 采购订单

展示字段：采购单号 / 供应商 / 收货门店 / 订购数量 / 已收数量 / 已退数量 / 总金额 / 状态 / 制单人 / 创建时间 / 操作。

### 状态流转

```text
草稿 →（提交审核）→ 待审核 →（审核通过）→ 已审核 →（收货入库）→ 部分收货 → 已完成
                                                    ↘（退货）    部分退货 / 已退货
   ↘ 取消                                                    
```

| 状态 | 含义 | 可做什么 |
| --- | --- | --- |
| 草稿 | 刚建的单 | 编辑、删除、提交审核 |
| 待审核 | 等待审批 | 审核通过、撤销审核 |
| 已审核 | 审批通过，等待收货 | 收货入库、退货、取消 |
| 部分收货 | 已收了一部分 | 继续收货入库 |
| 已完成 | 全部收完 | 看详情 |
| 已取消 | 作废 | 看详情 |

### 完整采购流程

1. **新建采购订单**：选择供应商、收货门店，逐行添加商品与订购数量，保存为草稿
2. **提交审核**：确认无误后提交，单子进入待审核
3. **审核通过**：有审批权限的人审核，可填审核备注；发现填错可「撤销审核」退回草稿
4. **收货入库**：点「收货入库」，在弹窗中填本次实收数量（可以小于可收数量，支持**部分收货**）与批次号，确认后直接入库
5. 收完后订单变为**已完成**；只收一部分则是**部分收货**，可继续收货

::: tip 收货即入库
确认收货入库后，系统直接生成入库单并加到**仓库**库存，不需要再去入库管理页操作一遍。入库单在「仓库管理 → 入库管理」可查。
:::

**收货后别忘了上架**：货进的是仓库，还要在[出库管理做上架](/guide/inventory)才能在收银台销售。

### 从订单发起退货

已审核或部分收货状态下，行操作 → **退货**，会跳转到采购退货页并自动带出来源采购单。

## 采购退货

路径：采购管理 → 采购退货

展示字段：退货单号 / 来源采购单号 / 供应商 / 退货数量 / 退货金额 / 状态 / 退货原因 / 操作人 / 创建时间 / 操作。

### 状态流转

```text
草稿 →（提交审核）→ 待审核 →（审核通过）→ 已审核 →（确认退货）→ 已退货 →（作废）
```

| 状态 | 含义 | 可做什么 |
| --- | --- | --- |
| 草稿 | 刚建的退货单 | 编辑、删除、提交审核 |
| 待审核 | 等待审批 | 审核通过 |
| 已审核 | 待退货 | 确认退货 |
| 已退货 | 库存已扣减 | 作废 |
| 已作废 | 已回滚 | 看详情 |

### 操作要点

1. **新建采购退货单**：选择来源采购单与供应商，添加要退的商品与数量
2. **提交审核 → 审核通过**：审核通过后**还要确认退货**才会扣减库存
3. **确认退货**：库存扣减，采购订单的已退数量同步更新。确认后**不能再改明细**
4. **作废**（如需）：恢复已扣减的库存与采购订单的已退数量

::: warning 审核 ≠ 退货
审核通过只是走完审批流程，库存还没动。必须再点「确认退货」才真正扣库存。
:::

## 权限

采购模块的操作需要按钮权限，看不到按钮说明没有被授权：

| 动作 | 说明 |
| --- | --- |
| 提交审核 | 采购订单提交 |
| 审核通过 | 审批权限 |
| 收货入库 | 收货权限 |
| 确认退货 | 退货执行权限 |
