# 客户与门店（超管）

> 「租户管理」与「平台管理」。**仅平台超级管理员可用**，用于管理平台上的各个客户（租户）及其门店。

## 先理解「租户」这个概念

一个**租户** = 一家客户公司，拥有独立的用户、门店、商品、订单数据，彼此完全隔离。连锁集团下有多家门店，门店归属于租户。

```text
平台（超管）
 └ 租户 A（客户公司）
    └ 门店 A1 / A2
 └ 租户 B
    └ 门店 B1
```

## 租户列表

路径：租户管理 → 租户列表

展示字段：客户名称 / 套餐 / 联系人 / 电话 / 门店数 / 用户数 / 商品数 / 到期时间 / 状态 / 创建时间 / 操作。

### 新增客户

1. 点 **新增客户**
2. 填写客户名称、联系人、电话
3. 选择**套餐**（必填）与**到期时间**（必填，默认今天 + 1 年）
4. 编码留空会自动生成
5. 保存

| 状态 | 含义 |
| --- | --- |
| 正常 | 正常使用 |
| 停用 | 暂停使用 |
| 过期 | 已过到期时间，需续费 |

### 其他操作

| 操作 | 说明 |
| --- | --- |
| 门店 | 跳转到门店列表并预选该客户 |
| 编辑 | 修改资料、套餐、到期时间；**续费改到期时间即可** |
| 切换 | 切换到该租户视角，用于排查该客户的问题 |
| 删除 | 会清理其下属业务数据 |
| 重置演示数据 | 清空该客户的全部业务数据并恢复演示数据 |

::: danger 重置演示数据不可恢复
这是给演示环境用的，会清空真实业务数据。操作前务必确认该租户是演示账号。
:::

## 品牌门店

路径：租户管理 → 品牌门店

展示字段：门店名称 / 所属客户 / 地址 / 联系电话 / 类型 / 营业时间 / 状态 / 操作。

### 新增门店

1. 点 **新增门店**
2. **必须先选所属客户**（编辑时不可改）
3. 填写门店名称、编号、地址、电话、类型、营业时间
4. 保存

| 类型 | 含义 |
| --- | --- |
| 直营 | 总部直营 |
| 加盟 | 加盟店 |

| 状态 | 含义 |
| --- | --- |
| 营业 | 正常运营 |
| 装修 | 装修中 |
| 暂停 | 暂停营业 |
| 关闭 | 已关闭 |

行内可直接切换 **营业 ↔ 暂停**。

::: tip 门店是库存与数据的分界线
库存、订单、收银数据都按门店隔离。收银员在收银台选错门店，库存会扣到别的门店，日结数据也会跟着错。
:::

## 套餐管理

路径：租户管理 → 套餐管理

展示字段：套餐名 / 价格 / 用户上限 / 门店上限 / 商品上限 / 状态 / 使用租户数 / 说明 / 创建时间 / 操作。

- 价格展示为 `¥ X / 时长`，时长按 365 / 30 的倍数自动显示为「N 年」「N 个月」
- **上限填 0 = 不限**
- 套餐在新增客户时必选，客户的到期时间就是套餐有效期截止日
- 「使用租户数」显示引用该套餐的客户数量，改套餐前先看影响面
- 支持新增与编辑，**无删除**（有客户在用就不能删）

## 系统管理工作台

路径：平台管理 → 系统管理工作台。纯看板，无操作按钮。

四张统计卡：租户总数 / 活跃租户 / 门店总数 / 系统用户。

| 区块 | 内容 |
| --- | --- |
| 近 6 个月租户开通趋势 | 累计开通租户数 |
| 套餐分布 | 环形图，各套餐客户占比 |
| 租户状态分布 | 正常 / 停用 / 已到期 |
| 30 天内到期租户 | 客户名单 + 套餐 + 到期时间，提示续费 |

每天扫一眼「30 天内到期租户」，提前联系客户续费。
