# 快速上手

> 第一次使用系统，看完这一篇就可以开始干活了。

## 登录

在登录页输入**账号**与**密码**进入系统。账号由管理员在「系统管理 → 用户管理」中开通，密码忘记请联系管理员重置，**不要反复尝试错误密码**（失败记录会进登录日志）。

## 界面分区

进入后看到四个区域：

| 区域 | 位置 | 作用 |
| --- | --- | --- |
| 侧边栏 | 左侧 | 功能菜单，点击后在工作区打开页面 |
| 多标签栏 | 内容区顶部 | 已打开的页面标签，右键可关闭其他/全部 |
| 消息滚动条 | 多标签栏下方 | 滚动播放**未读**的公告/通知/提醒标题，点击直接看详情 |
| 铃铛图标 | 右上角 | 未读消息数量与消息中心入口 |
| 工作区 | 中间 | 具体操作页面 |

::: tip 消息滚动条
滚动条只滚动**你有权限接收且未读**的消息。公告为红色、租户通知为主题色、事件提醒为橙色，看完即消失，也可点右侧 × 关闭本次展示。
:::

## 四类角色看到的菜单不一样

系统按角色控制菜单可见范围，**看不到某个菜单 = 当前账号没有被授权**，不是系统漏装了功能。

| 角色 | 能看到什么 |
| --- | --- |
| **超级管理员** | 全部菜单，包含「平台管理」「租户管理」（管客户、门店、套餐） |
| **租户管理员** | 本客户（租户）内的全部业务菜单 + 「租户通知」 |
| **店长** | 本门店范围内的收银、库存、采购、经营数据；发通知只能发本门店 |
| **收银员** | 收银台、会员、订单查询等日常作业功能 |

需要更多权限时，找租户管理员在「系统管理 → 用户管理」中调整角色。

## 收款前必须做的几件事

收银台以及库存、订单数据都按**门店**隔离，用之前先确认门店是对的：

1. 进入「收银管理 → 收银台」
2. 看页面顶部的**销售门店**下拉，切换到你所在的门店
3. 门店选错会导致库存扣减到别的门店，日结数据也会错

## 典型的一天

```text
开店  → 收银台选门店 → 有顾客就扫码开单收款
      → 顾客退货：订单管理 → 销售订单 → 发起退货

补货  → 仓库管理 → 库存查询 → 看哪些商品货架不足
      → 仓库有货：出库管理 → 新建上架单 → 确认上架
      → 仓库没货：采购管理 → 新建采购订单 → 审核 → 收货入库

盘账  → 财务管理 → 日结管理（看当天收款与退款）
      → 工作台 → 经营驾驶舱（看今日销售、热销排行）

收工  → 财务 → 收支流水 核对当日每一笔收款
```

## 常见疑问

**菜单里没有我要的功能？**
先确认账号角色是否正确；若角色正确仍缺菜单，说明该菜单没有被授权给这个角色，需要管理员在「角色管理 → 菜单权限」中勾选。

**页面显示「暂无数据」？**
多为筛选条件过窄或数据本就不存在。先清空筛选条件再看；仍为空则确认是否选错了门店。

**操作按钮点了没反应？**
按钮级权限未授权时会不显示或不可用。找管理员在「菜单管理」中确认该按钮的权限标识已挂到角色上。
