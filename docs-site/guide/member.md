# 会员管理

> 「会员管理 → 会员列表」，会员档案、储值卡充值与消费留痕。

## 会员列表

展示字段：序号 / 会员编号 / 姓名 / 手机号 / 会员等级 / 性别 / 余额 / 积分 / 累计消费 / 状态 / 注册时间 / 操作。

顶部搜索可按姓名、手机号等条件检索。

### 等级与状态

| 等级 | 标签 |
| --- | --- |
| 普通会员 | 灰色 |
| 银卡会员 | 绿色 |
| 金卡会员 | 橙色 |
| 钻石会员 | 红色 |

| 状态 | 含义 |
| --- | --- |
| 正常 | 可在收银台关联、享受会员价 |
| 停用 | 不能享受会员价，收银台关联时会提示 |

## 新增会员

1. 点 **新增会员**
2. 填写姓名、手机号（必填）、性别、生日、等级、邮箱、地址
3. 点 **确定**

手机号必须是 11 位有效号码（1 开头），格式不对会提示「请输入正确的手机号」。生日不能选未来日期。

## 充值

1. 在会员行点 **充值**
2. 填写充值金额（0.01 ~ 999999）、赠送金额（0 ~ 999999）
3. 选择支付方式（现金 / 微信 / 支付宝 / 银行卡）
4. 填写备注（选填，最多 200 字）
5. 点 **确定充值**

弹窗会实时显示**实际到账** = 充值金额 + 赠送金额，充值前先和系统里收到的现金对一下。

## 查看会员记录

行操作 → **记录**，抽屉里两个页签：

| 页签 | 内容 |
| --- | --- |
| 充值记录 | 充值时间 / 充值金额 / 赠送金额 / 充值前余额 / 充值后余额 / 支付方式 / 操作员 / 备注 |
| 消费记录 | 订单号 / 消费金额 / 实付金额 / 支付方式 / 订单状态 / 消费时间 / 门店 |

## 删除会员

删除会**连带删除该会员的充值记录**，确认文案会提示。删除后不可恢复，请先确认不再需要该会员的历史记录。

## 在收银台使用会员

1. 收银台输入会员手机号 → 查询 → 关联
2. 商品价格自动按会员价计算（收银员不能手工改折扣）
3. 支付方式可选**储值卡**，扣会员余额
4. 解除会员后，储值卡支付方式会自动回退为现金

::: tip 储值卡余额不足
会员余额不够时会提示更换支付方式或减少商品，不能透支。
:::
